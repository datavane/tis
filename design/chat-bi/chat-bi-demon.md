# TIS 5.1.0 ChatBI 功能演示

## 演示背景

大家好！今天我要给大家演示的是 TIS 5.1.0 版本中新增的一个重要功能——基于本体语义层的 ChatBI 系统。

什么是 ChatBI 呢？简单来说，就是让你用自然语言直接问数据库问题，系统自动帮你生成 SQL 并返回结果。比如你可以直接问"上个月销售额最高的产品是什么"，而不需要自己写复杂的 SQL 查询。

为了让大家更直观地了解这个功能怎么用，我们今天会从零开始搭建一个完整的 Demo。整个流程是这样的：我们先把 MySQL 中的数据同步到 Doris，然后在 Doris 上构建本体语义层，最后通过 Falcon 测试数据集中准备好的自然语言问题来测试 ChatBI 的效果。

这里需要解释一下什么是"本体语义层"。简单说，就是在原始数据表之上，构建一层业务语义的抽象。它会告诉系统：哪些字段是维度、哪些是度量，表之间是什么业务关系，字段对应什么业务术语。有了这一层，AI 就能更准确地理解业务问题，而不是仅仅靠字段名去猜测。

### 关于测试数据集

这次演示，我们使用的是 Eosphoros AI 出品的 Falcon 测试数据集（https://github.com/eosphoros-ai/Falcon）。这是一个企业级的中文 Text-to-SQL 评测基准，专门针对 MaxCompute、Hive 这类复杂查询场景，特别关注中文语义的歧义问题，涵盖了金融、互联网、零售等多个领域。

我们会使用 Falcon 中的一个零售场景的子数据集，这个场景包含四张表：
- **products**（产品表）
- **stores**（门店表）
- **inventory**（库存表）
- **sales**（销售表）

这四张表的关系可以参考 ER 图：`design/chat-bi/img/er_diagram_toy_retail_20260821_124445.png`

所有的 ChatBI 测试都是围绕这四张表展开的。具体的测试用例在 `/opt/misc/Falcon/test_exam/14/test_exam.md` 这个文件里，包含了几十个精心设计的中文问题，涵盖简单查询、多表关联、聚合计算等多种场景。我们的目标是让 ChatBI 能够准确理解并正确回答这些业务问题。

### 这个 Demo 能展示什么？

通过这个演示，大家可以感受到三个核心价值：

1. **更高的准确性**：基于本体语义层构建的 Graph RAG 方式，相比传统的 Embedding RAG，能够大幅提高 ChatBI 的查询准确性。简单说，Graph RAG 通过知识图谱的方式理解表之间的关系，而不仅仅是向量相似度匹配，所以能更准确地理解用户的意图。具体来说，TIS 的 Graph RAG 采用了 4 路并行召回加子图扩展的策略：通过业务术语词典、表关系图谱、字段语义角色等多个维度同时检索相关信息，然后扩展出完整的子图结构，这样就能理解复杂的多表关联查询。

2. **开箱即用**：TIS 把数据集成功能与本体语义层有机融合在一起，用户不需要额外配置复杂的知识图谱工具，就能直接使用 ChatBI 功能，非常方便。

3. **灵活扩展**：TIS 的所有功能都是基于插件架构的，任何功能都可以通过安装插件实现热部署、热生效，不需要重启服务。这为未来的功能扩展留下了充足的空间。

## 演示环境

这次演示我会在一个已经安装好 TIS 5.1.0 的环境中进行。MySQL 和 Doris 都已经准备就绪。如果你想跟着动手试试，只需要一个 Docker 环境就可以快速启动 TIS。整个演示大概需要 20-30 分钟。

## 测试步骤

整个 Demo 分为以下六个步骤：

### 1. 数据准备
将 MySQL 中的数据集同步到 Doris 库中。这一步展示 TIS 的数据集成能力，也是后续所有工作的基础。

### 2. 本体 Object Type 映射
把 Doris 库中的表映射到本体域中。这一步是建立语义层的第一步，告诉系统哪些表对应哪些业务概念。

### 3. 本体实例自动推导
这一步是为开启 ChatBI 做准备。手工创建本体资源是个非常细致繁琐的工作，但是利用大模型的推理能力，我们可以自动完成 90% 的工作量。这是TIS中的一个功能亮点。系统会自动推导出表之间的关系、字段的语义角色、业务术语等等。比如，系统会自动识别出 product_id 是一个维度字段，sales_amount 是度量字段，products 表和 sales 表之间是一对多的关系，"销售额"这个业务术语对应的是 sales_amount 字段，等等。

### 4. 本体资源修剪
对自动生成的本体资源进行人工审核和调整。虽然大模型很强大，但最终还是需要人工把关，确保语义层的准确性。

### 5. 开启 ChatBI
ChatBI 在 TIS 中被设计成本体域的一个技能包，可以单独开启。这体现了 TIS 的模块化设计思想。

### 6. 效果演示
最后，我们会用两种方式展示 ChatBI 的效果：

   **方式一：TIS 后台直接测试**  
   在 TIS 后台提交自然语言查询，可以实时看到 ChatBI 执行管道的整个处理流程，包括问题理解、SQL 生成、执行结果等各个环节。

   **方式二：集成到 Agent 中使用**  
   在生产环境中，我们还可以通过 TIS 提供的 MCP 工具，把 ChatBI 能力集成到 Claude Desktop 或者 Hermes Agent 这样的智能助手中。在这些 Agent 里进行自然语言问数，配合它们丰富的可视化渲染插件，可以获得更加强大和灵活的数据分析体验。

通过这个完整的演示，你不仅能看到 ChatBI 的实际效果，还能了解到如何在自己的项目中使用 TIS 来构建类似的系统。演示中用到的所有数据集、配置文件、测试用例，我都会在演示后提供下载链接。
